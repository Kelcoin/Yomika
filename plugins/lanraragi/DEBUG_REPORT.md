# Yomika Bridge 调试记录

2026-11-09；插件 1.1.0，协议 1。范围为 `plugins/lanraragi/**`，未修改或连接用户生产服务器。该报告描述插件本身，客户端整合验收由主任务执行。

## 已定位并修复

| 问题 | 原因与修复 | 验证 |
| --- | --- | --- |
| 搜索预设、非重复标记无法按记录扩展 | 通用 workspace 是1800字节整文档。新增独立集合 hash 与稳定有序索引、逐条CAS版本和墓碑；无集合总大小上限。 | 65条记录分两页读取，含删除墓碑；不同key独立写入。 |
| JSON空数组被Lua误变为空对象 | Redis cjson空table编码为`{}`。任意JSON业务值以canonical JSON字符串保存，响应拼接该JSON；空states显式规范化。 | 嵌套空数组、空集合分页、缺失/墓碑null测试。 |
| JSON数字可能被当作预设字符串 | Perl标量可隐式字符串化。业务文本检查实际JSON字符串编码，再做枚举和字段校验。 | 数字name/query、额外字段、非法sortBy拒绝。 |
| 过期写入可能绕过进度内容校验 | transition原先在校验progress前返回冲突。现先完整校验，再返回CAS冲突。 | stale版本且pageCount0仍返回INVALID_REQUEST。 |
| LANraragi删除留下桥接记录与非重复关系 | 无原生删除hook；增加读取批次与hello持久游标有界清理，删除阅读字段并保留递增generation，关系保留版本墓碑。 | 真实Redis档案hash DEL后states/get清理；索引移除、世代递增、重复清理不重复写。 |
| 短暂Redis故障可能被误判为档案删除 | 只接受成功显式HEXISTS=0。先检查完整候选批次再CAS清理，异常传播。 | 注入档案Redis timeout，确认version和progress不变。 |
| 已成功操作在后续写入或删除后重试 | 永久operations账本保存原始成功/冲突响应及请求摘要，先查账本后查档案存在性；清理不改账本。 | 后续修改、墓碑、档案DEL之后重试仍逐字段等于原始响应；ID复用拒绝。 |

## 审查结论与边界

- 所有公开action保持protocol1；hello标明collections能力。内部reconcile动作不在公开dispatch允许列表，客户端无法伪造删除证据。
- 身份通过Lua HSETNX持久创建，常规升级不改变serverId/epoch。读取、冲突、成功携带当前身份；旧幂等响应保留原全局版本，客户端不能以此当作最新快照。
- 状态/索引/CAS/全局版本/结果账本同一Lua提交；无HGETALL、KEYS或全库扫描。读取最多50个指定状态，列表/导出最多100个，集合最多50个，hello最多20+20候选。集合分页为ZRANGE+当前页HGET，时间随当前页及索引查找增长，不随整集合反序列化增长。
- 请求UTF8最多6000字节，URL编码arg最多5900；workspace值1800字节，集合值4000字节。ASCII JSON转义最坏膨胀也受每页条数约束，集合响应上界约1.3MB以内。测试覆盖50条大型记录聚合响应；不是每种最坏字符排列的性能基准。
- 进度只允许有效页范围、layout/direction枚举和bool封面偏好；`>90%`移出待看，恰好90%保留。回退需显式授权；清除推进generation。历史和待看索引保持各自时间语义，不因无关修改重排。
- 查询/参数/错误不记录API密钥或完整URL；内部异常只映射稳定错误码。Redis基础设施错误可能无法返回完整身份信封，客户端必须按网络/服务错误处理。
- 从本地上游源码核对：`LANraragi/Model/Archive.pm::delete_archive`删除档案Redis hash；`Utils/Database.pm`创建file字段且某些流程使用空file标记。因此只检查HEXISTS，不以空路径、磁盘离线或无封面推断删除。

## 客户端整合链路复核

客户端复核补齐以下修复，并提供回归测试：

- 删除清理后列表可能不足一整页，客户端按实际返回数量推进游标；空页但仍有总数时只允许有界重试。
- 永久操作账本的回执代表当时结果。客户端确认成功后另取当前state/record，再清理队列并更新镜像；有后续待提交修改时保留乐观镜像，避免旧回执恢复已删除数据。
- 历史/待看列表缺项时读取真正的服务器记录，不以本机清空时间戳伪造新状态。历史已隐藏但仍有进度的档案也纳入对账，才能清理已删档案的进度和世代。
- 原生入队也校验预设字段白名单、文本长度、4000字节记录限制，以及进度最大页数与布尔偏好，避免永久失败的内容污染本机队列。
- 搜索预设和非重复标记使用专用集合与离线队列；扫描前刷新关系，版本变化后更新已挂载页面。普通未托管模式保持本机存储。
- 旧云同步代码已移除；显式文件备份独立读表，不依赖已删除的日志。数据库迁移有记录保留和清除进度意图回归测试。
